5Suggested README hero (drop-in)

Replace the current opening with this. Library framing leads; screenshot first; binary demoted.

# jobhunt

**A local-first Python library and CLI for scraping ATS job boards.**
Like JobSpy, but with a saved-search UI, CV ranking, and nothing leaving your machine.

![jobhunt search page with filters applied](docs/screenshot-search.png)

## Why this exists

Job sites optimise for engagement, not your job search. LinkedIn wants you
back tomorrow. Indeed wants the email. JobHunt scrapes the same boards those
sites scrape — Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Recruitee,
Workday, RemoteOK, HN "Who is Hiring" — then keeps the data on your laptop
where you can filter, rank, and forget about it.

## Quickstart (developers)

```python
from jobhunt.scrapers import GreenhouseScraper

async for job in GreenhouseScraper("stripe").scrape():
    print(job.title, job.location)
```

Or run the bundled web UI:

```bash
pipx install jobhunt
jobhunt scrape    # pull listings from configured boards
jobhunt app       # opens http://127.0.0.1:8765
```

<details>
<summary>Prebuilt binaries (Linux x86_64, macOS arm64, Windows x86_64)</summary>

Binaries are unsigned (no $300/yr cert for a solo project). SHA-256
checksums are published with each release — verify before running.

Windows users: Defender may quarantine the .exe (not just SmartScreen).
If `jobhunt` "command not found" after install, check Windows Security
→ Protection history.
Intel Mac users: no prebuilt binary yet — install from source.

</details>

## What you should know before you trust this

- **CV ranking downloads ~80 MB from HuggingFace on first use**
  (all-MiniLM-L6-v2, cached locally after). Everything else is local.
- **`jobhunt app` binds to 127.0.0.1.** `jobhunt serve --host 0.0.0.0`
  exposes it to your LAN with no auth — don't.
- The "freshness" sort is recency + description length + keyword count.
  It's not a model of you; calling it "relevance" would be a lie.
- Listing counts depend on configured boards in `sources.yaml`.
